# Conecta Turma

Aplicativo Flutter de quebra-gelo para aproximar grupos por meio de perguntas leves, histórias e colaboração.

## Funcionalidades

- três categorias com 15 perguntas e perguntas de apoio;
- navegação entre início, rodada, favoritas e sobre;
- persistência local de perguntas favoritas e total respondido;
- layout responsivo para Android e Web;
- testes de interface e navegação;
- publicação contínua no GitHub Pages.

## Executar localmente

Pré-requisito: Flutter 3.38 ou mais recente.

```bash
flutter pub get
flutter run
```

Para executar no navegador:

```bash
flutter run -d chrome
```

## Qualidade

```bash
flutter analyze
flutter test
```
